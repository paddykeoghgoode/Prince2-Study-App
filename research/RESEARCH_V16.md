# PRINCE2 Revision Studio v16 — Syllabus Mastery

Release: 2 November 2026  
Primary authority: **PRINCE2 Project Management Foundation, syllabus v7.2 (April 2025)**, supplied by the learner.

## What has changed

- **120 additional original multiple-choice questions** (`SY16-001` to `SY16-120`), raising the original bank from **700 to 820**. Other official/user-supplied sample sets remain separate.
- Every new question has **four separately written explanations**, including definitions and reasons why plausible alternatives do not answer the question.
- Format breakdown: **105 standard**, **5 missing-word**, **10 two-correct-statement list** questions. The previous bank retains exceptional negatively worded questions.
- The new **Syllabus Mastery Lab** includes a topic filter, format filter, unseen-only mode, 10/20-question guided sessions, 20/30/40/60-question timed practice, and a focused retest of missed questions.
- **Terminology clinic:** 15 contrasts, each linking to focused practice.
- The original app's games, study lessons, source reader, notes, XP, revision history and existing question banks are retained.
- The existing PDF assets in the Android APK have been preserved (10 source PDFs and 402 offline document page images).

## Installation on Poco F8 Ultra

Download the `PRINCE2_Revision_Studio_v16_Syllabus_Mastery_Poco_F8_Ultra.apk` and install over the **v15 Exam Arcade / Fresh Question Lab** app. The package uses the same identity and signing certificate as v15 so it is intended to update the existing app while retaining local storage. Export a progress backup from v15 first when possible. Older companion versions (v13 etc.) may have a different package identity, so they will remain separate.

If Android blocks installation, check the phone's security prompt and only permit installation from the source you deliberately used. Do not uninstall the old app until your progress has been backed up and you have confirmed the new installation works.

The standalone HTML can be opened in a desktop or mobile browser and includes the question bank and extracted lesson/document text. Full offline PDF diagrams/pages are bundled in the APK, not in the standalone HTML.
